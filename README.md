# SKM Cinematic Generator

A Blender 5.2 LTS add-on for generating a cinematic South Indian Vijayanagara-inspired sanctum for the Singanal Ka Maharaj project.

## Status

Initial scaffolding.

## Goals

- One-click sanctum generation inside Blender
- Procedural architecture, materials, lighting, and camera setup
- Optimized for Blender 5.2 LTS on Windows 11 with RTX 3060

## Planned Features

- Sanctum blockout generator
- Procedural granite and bronze materials
- Cinematic lighting presets
- Camera setup and composition helpers
- Future logo reveal animation tools

## Repository Layout

- `addon/` Blender add-on source
- `docs/` project notes and references
- `examples/` usage examples
